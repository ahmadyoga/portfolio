# Optional 3D / WebGL

## Principle

3D is optional.

Only introduce:

- Three.js
- React Three Fiber
- WebGL

if it meaningfully improves the visual identity.

## Preferred Use

One excellent lightweight interactive 3D element is better than a website full of mediocre 3D.

A suitable location is the hero.

## If 3D Is Used

Requirements:

- lightweight scene
- simple/procedural geometry where possible
- avoid giant models
- responsive behavior
- pause/reduce rendering when offscreen where practical
- reduced-motion fallback
- no blocking initial load

## Performance

Never sacrifice portfolio usability for visual novelty.

If a 3D element does not clearly improve the experience, remove it.

## Interaction

Possible inputs:

- mouse position
- subtle camera movement
- scroll progression
- hover

Keep movement controlled and purposeful.
