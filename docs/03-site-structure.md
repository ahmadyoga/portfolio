# Site Structure

Create the following major sections:

1. Hero
2. Selected Work
3. Project Case Studies
4. Engineering Approach
5. Skills / Technology
6. GitHub / Open Source
7. About
8. Contact

## Navigation

Desktop:

- sticky navigation
- compact
- contextual/transparent when appropriate
- active section indicator

Mobile:

- elegant menu transition
- accessible
- touch-friendly
- no hover dependency

Navigation should never obscure content.

## Continuous Experience

The page should feel like one connected narrative.

Avoid:

```text
Hero
↓
Card
↓
Card
↓
Card
↓
Footer
```

Prefer:

```text
Hero
↓
Hero transition
↓
Selected work
↓
Project storytelling
↓
Technical explanation
↓
Engineering philosophy
↓
Proof
↓
Contact
```
