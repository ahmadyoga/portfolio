# Claude Code Implementation Workflow

## Phase 1 — Inspect

Before changing code:

1. Inspect the repository.
2. Identify framework.
3. Inspect package/dependency setup.
4. Inspect existing routes.
5. Inspect existing components.
6. Inspect assets.
7. Inspect README files.
8. Inspect Git history where useful.
9. Identify verified project information.
10. Identify missing information.

Do not begin by blindly replacing the existing project.

## Phase 2 — Plan

Create a concise implementation plan covering:

- page architecture
- component architecture
- content/data model
- animation system
- responsive strategy
- asset strategy
- performance strategy

Then implement.

## Phase 3 — Build

Build the complete experience:

- navigation
- hero
- selected projects
- project case studies
- engineering approach
- skills
- GitHub
- about
- contact
- responsive behavior
- animation system

Do not stop after the homepage.

## Phase 4 — Validate

Run:

- lint
- type checking
- production build

Then fix all errors.

## Phase 5 — Review

Check:

- desktop
- tablet
- mobile
- keyboard navigation
- reduced motion
- route transitions
- project links
- external links
- image loading
- GitHub fallback
- animation cleanup
- console errors

## Phase 6 — Polish

Only after functionality is stable:

- tune typography
- tune spacing
- refine easing
- refine transitions
- remove unnecessary effects
- improve visual hierarchy
- improve performance

Do not add effects simply because the page feels "too empty."

Use composition and typography before adding more animation.
