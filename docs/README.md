# Ahmad Yoga Portfolio — Claude Code V2 Prompt

This directory contains the full Claude Code V2 specification, split into focused Markdown files.

## Files

- `00-overview.md` — overall project context and positioning
- `01-objectives.md` — goals and success criteria
- `02-design-direction.md` — visual language and design principles
- `03-site-structure.md` — page architecture and navigation
- `04-hero.md` — hero content and entrance experience
- `05-projects.md` — selected work and project interaction
- `06-case-studies.md` — technical case-study structure
- `07-interaction.md` — animation and interaction principles
- `08-animation-architecture.md` — reusable motion architecture
- `09-3d.md` — optional Three.js/WebGL direction
- `10-engineering-approach.md` — engineering philosophy section
- `11-skills.md` — technology presentation
- `12-github.md` — GitHub integration
- `13-about-contact.md` — about and contact sections
- `14-content-rules.md` — anti-fabrication and content rules
- `15-technical-requirements.md` — frontend architecture and requirements
- `16-performance.md` — performance requirements
- `17-accessibility.md` — accessibility requirements
- `18-seo.md` — SEO and metadata
- `19-error-handling.md` — resilience and fallbacks
- `20-quality-bar.md` — final quality criteria
- `21-implementation-workflow.md` — Claude Code execution workflow
- `22-final-creative-direction.md` — final creative direction and decision rules

## Recommended Use

Give Claude Code the entire directory as the project specification.

If working incrementally, start with:

1. `00-overview.md`
2. `01-objectives.md`
3. `02-design-direction.md`
4. `03-site-structure.md`
5. `07-interaction.md`
6. `08-animation-architecture.md`
7. `21-implementation-workflow.md`

Then provide the remaining files as the detailed specification.

## Important

The specification deliberately separates:

- product/content requirements
- visual direction
- interaction/motion
- architecture
- performance
- accessibility
- truthfulness
- implementation workflow

This makes it easier to modify one aspect without rewriting the entire prompt.
