# Ahmad Yoga Portfolio — Claude Code V2

## Purpose

Build a production-quality, interactive personal portfolio for **Ahmad Yoga Witdodo**, a Mobile Software Engineer.

The portfolio is intended to help Ahmad secure interviews for Mobile Software Engineer / Flutter Engineer roles.

This is not a generic developer portfolio. It should demonstrate both:

1. The quality of the products Ahmad has built.
2. The engineering, interaction design, and attention to detail behind the portfolio itself.

Desired impression:

> "This engineer knows how to build software, understands product experience, and has strong attention to detail."

## Core Positioning

**Name:** Ahmad Yoga Witdodo  
**Role:** Mobile Software Engineer  
**Primary focus:** Flutter, Android, iOS, mobile application development  
**GitHub:** https://github.com/ahmadyoga

## Primary Goal

Create a portfolio that is:

- technically credible
- visually distinctive
- interactive
- fast
- accessible
- easy to understand
- memorable without being gimmicky

## Experience Goal

The site should feel like a continuous interactive story:

```text
ENTRY
  ↓
INTRODUCTION
  ↓
WHO IS AHMAD?
  ↓
WHAT HAS HE BUILT?
  ↓
HOW DOES HE BUILD?
  ↓
TECHNICAL DEPTH
  ↓
PROOF / GITHUB
  ↓
CONTACT
```

The visitor should progressively discover Ahmad's capabilities rather than simply scrolling through a collection of static cards.
