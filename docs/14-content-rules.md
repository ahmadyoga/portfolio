# Content & Truthfulness Rules

## Critical Rule

Never fabricate information.

Do not invent:

- employment history
- job titles
- years of experience
- project metrics
- number of users
- revenue
- app downloads
- performance improvements
- client names
- awards
- certifications
- contributions
- technical implementations
- business outcomes

If information is missing, use:

```text
[PLACEHOLDER]
```

or omit the claim.

## Interview Defensibility

Every meaningful claim on the portfolio should be something Ahmad could confidently defend in an interview.

The portfolio should demonstrate competence through evidence rather than adjectives.

Avoid excessive use of:

- passionate
- innovative
- cutting-edge
- results-driven
- world-class
- leveraging technology

## Project Content

Only describe Ahmad's personal contribution when it is known.

Clearly separate:

- project capability
- Ahmad's actual contribution
- team/project context

Never imply personal ownership of work without evidence.
