# Engineering Approach

Create a section explaining how Ahmad approaches software engineering.

Use approximately 4–6 principles.

Possible themes:

- product-first thinking
- predictable business logic
- maintainability
- API/backend integration
- debugging and problem solving
- performance
- testing
- deployment
- iterative development

## Tone

Avoid generic corporate language.

Bad:

> "I leverage cutting-edge scalable solutions."

Better:

> "I care about keeping business logic predictable, testable, and independent from UI state."

The section should feel personal and concrete.

## Animation

Use:

- staggered reveals
- typography transitions
- subtle line movement
- progressive highlighting

Motion should support the explanation.
