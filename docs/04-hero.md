Use:

**AHMAD YOGA**

**Mobile Software Engineer**

**Flutter · Android · iOS · Backend**

> Building reliable mobile products with Flutter, Android, and iOS.

You may improve this wording if you can make it stronger while keeping it authentic and concise.

## CTA

Include:

- View Projects
- GitHub
- Contact

## Hero Entrance Choreography

On initial load:

1. Background initializes subtly.
2. Main typography reveals.
3. Name enters with staggered motion.
4. Role appears after the name.
5. Supporting text follows.
6. CTA buttons appear.
7. Secondary visual settles into place.
8. Scroll indicator begins subtle motion.

Target total entrance sequence:

**approximately 0.8–1.5 seconds**

Do not delay usability.

## Hero Visual

Create one distinctive visual element.

Possible directions:

### A. Abstract mobile system

Stylized representation of mobile UI layers, device frames, or interface components.

### B. Technical system visualization

Abstract representation of:

```text
Flutter
   ↓
Application
   ↓
Backend
   ↓
Database
```

### C. Minimal 3D

If Three.js / React Three Fiber genuinely improves the design, use one lightweight 3D hero element.

Do not turn the entire website into a 3D experience.

## Hero Scroll Transition

The hero should transition into the next section instead of simply disappearing.

Possible behaviors:

- typography moves vertically
- visual element shifts perspective
- background depth changes
- hero content scales subtly
- next section emerges underneath

Use ScrollTrigger for a controlled transition.

Keep it elegant and short.
