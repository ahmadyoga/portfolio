# GitHub / Open Source

GitHub:

https://github.com/ahmadyoga

## Purpose

GitHub should act as supporting evidence for the portfolio.

If GitHub API integration is appropriate:

- fetch public repositories
- gracefully handle failures
- cache where appropriate
- do not require authentication
- never expose secrets
- do not make the portfolio dependent on the API

The site must remain functional if GitHub API access fails.

## Visual Presentation

Possible interaction:

- repositories appear progressively during scroll
- hover highlights repository details
- technology labels animate subtly
- links provide clear direction to GitHub

Do not turn the section into a dashboard.

The portfolio remains the primary experience.
