# Design Direction

## Visual Language

Aim for a premium software-engineer portfolio with the quality bar of:

- Linear
- Vercel
- Raycast
- Stripe
- Apple product pages
- high-quality Awwwards developer portfolios

These are references for quality and interaction, not designs to copy.

## Avoid

Do not create:

- generic Tailwind template aesthetics
- generic AI portfolio layouts
- excessive glassmorphism
- neon cyberpunk visuals
- random gradients
- excessive rounded cards
- excessive shadows
- noisy backgrounds
- unnecessary 3D
- "AI developer" visual clichés
- a resume converted into HTML

## Desired Characteristics

Use:

- strong typography
- excellent spacing
- clear hierarchy
- editorial composition
- subtle depth
- controlled contrast
- purposeful movement
- distinctive project presentation
- strong visual rhythm

## Dark-First

A dark-first aesthetic is preferred if it improves the design, but readability and accessibility are more important than forcing a dark theme.

## Visual Hierarchy

Every section should have an obvious:

1. entry point
2. primary message
3. supporting information
4. action or continuation

Do not make every element compete for attention.
